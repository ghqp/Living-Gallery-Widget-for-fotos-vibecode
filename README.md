# Living Gallery

Android-приложение с виджетами фотографий для главного экрана. Фото всегда стоит квадратом по центру ячейки виджета: при изменении размера снимок только обрезается и не искажается.

## Возможности

- Галерея виджетов сеткой или списком, счётчик активных виджетов, меню «Изменить», «На главный экран», «Дублировать», «Удалить».
- Редактор с живым превью: до 24 фото из галереи или Google Фото, смена порядка перетаскиванием, кадрирование каждого снимка.
- Рамки: круг, квадрат, скруглённая, арка, печенье, клевер. Обводка 0–10 dp с выбором цвета (в том числе «из фото»), скругление углов 0–48 dp.
- Цветовые тона: оригинал, ч/б, ярко, драма, тепло, холод, сепия, пастель, нуар.
- Смена фото по нажатию или по расписанию (от 15 минут до раза в день), по порядку или вперемешку.
- Размеры при добавлении: 2×2, 3×2, 2×3, 3×3, 4×2, 4×3. Виджет ставится из приложения или из списка виджетов лаунчера.
- Тёмная и светлая тема, цвета обоев на Android 12+, английский и русский интерфейс.

Без рекламы и без доступа к интернету.

## Сборка

Нужны Android Studio, JDK 17+ и Android SDK 37 (`compileSdk` 37, `targetSdk` 36, `minSdk` 26).

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

## Устройство кода

- `data` — модель виджета, хранилище на DataStore (`gallery.json`) с переносом виджетов версии 0.x, файлы фото.
- `render` — отрисовка рамки, обводки, тона и кадра. Её использует и превью в приложении, и виджет, поэтому они совпадают.
- `widget` — провайдеры виджета, RemoteViews, закрепление на главном экране, выбор дизайна из лаунчера, автосмена через WorkManager.
- `ui` — Jetpack Compose и Material 3: галерея, редактор, настройки.
